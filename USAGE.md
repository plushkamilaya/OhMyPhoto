# Как обновлять сайт

Все изменения делаются в двух местах:
- **`photos/`** — папка с исходными фотографиями
- **`pages.js`** — список разделов и порядок фото в каждом

После любых изменений запусти сборку:
```bash
npm run build
```

Проверить локально:
```bash
npm run dev
# открыть http://localhost:3000
```

---

## Добавить новые фотографии

1. Скопируй файлы в папку `photos/`
2. Открой `pages.js` и добавь имена файлов в нужный раздел:

```js
{
    name: 'Restaurants',
    images: [
        'ES7A6101.JPG',
        'НОВЫЙ_ФАЙЛ.jpg',   // ← добавить сюда
        ...
    ]
}
```

3. Запусти `npm run build`

Превью и полноразмерная версия сгенерируются автоматически. Повторная сборка пропустит уже обработанные фото — работает быстро.

---

## Удалить фотографии

1. Убери имя файла из `pages.js` (из всех разделов, где оно встречается)
2. Запусти `npm run build`

Файл в `photos/` можно не трогать — он просто не попадёт на сайт. Если хочешь убрать его и из билда тоже, удали вручную из `build/photos/`.

---

## Изменить порядок фотографий

В `pages.js` перетащи строки в нужном порядке — сверху вниз, слева направо:

```js
images: [
    'ES7A6137-1.jpg',   // первая в галерее
    'ES7A6143.JPG',     // вторая
    'ES7A3590.JPG',     // третья
    ...
]
```

Запусти `npm run build`.

---

## Создать новый раздел

Добавь объект в массив в `pages.js` — перед `about`, который всегда должен быть последним:

```js
{
    name: 'weddings',        // id раздела, используется в URL: plushka.se/#weddings
    title: 'Weddings',       // отображается в навигации и шапке
    template: 'gallery',
    images: [
        'IMG_1234.jpg',
        'IMG_5678.jpg',
    ]
},
```

Запусти `npm run build`. Раздел появится в навигации автоматически.

> **Важно:** имя (`name`) не должно содержать пробелы. Заглавные буквы сохраняются: `name: 'Kids'` → `/#Kids`.

---

## Удалить раздел

Удали весь объект раздела из `pages.js` и запусти `npm run build`.

---

## Изменить порядок разделов в навигации

Порядок объектов в массиве в `pages.js` — это порядок в меню. Просто переставь блоки местами. Раздел `index` всегда главная страница, в навигацию не попадает.

```js
const pages = [
    { name: 'index', ... },      // главная, в меню нет
    { name: 'Restaurants', ... }, // первый пункт меню
    { name: 'Kids', ... },        // второй
    { name: 'places', ... },      // третий
    { name: 'about', ... },       // последний
];
```

## Опубликовать изменения

После того как всё проверено локально:

```bash
git add photos/ pages.js
git commit -m "update photos"
git push
```

GitHub Actions автоматически соберёт сайт и задеплоит его на **preview**-адрес. Ссылка на preview появится в статусе Actions.

Чтобы выложить на **production** (plushka.se):
1. Открой вкладку **Actions** в репозитории
2. Слева выбери **Deploy to Cloudflare Pages**
3. Нажми **Run workflow** → поставь галку **Deploy to production? = true** → **Run workflow**
